# Count Vowels

## Problem Summary

Write a function that returns the number of vowels in a given string.  
Only `a`, `e`, `i`, `o`, and `u` are considered vowels.  
Input is guaranteed to be all lowercase letters and/or spaces.

## My Approach

- Use `.split('')` to turn the string into an array.
- Use a `for` loop to go through each character.
- Use `if` conditions to check if the character is a vowel.
- Use a counter variable to keep track of how many vowels are found.

## What I Learned

- Practiced looping through arrays.
- Practiced checking multiple conditions in one `if` statement.
- `.split('')` turns a string into an array of characters.

## Time Complexity

- Time: O(n)
- Space: O(1)
